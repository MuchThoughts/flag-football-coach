# Working on this repo

- When a change is finished and passes `npm run test:logic`, `npm run typecheck`
  and `npm run build`, merge it into `main` and push. Don't stop to ask first.
- Keep the UI as compact as possible: minimal white space, small headings,
  controls combined onto one row where they fit, and nothing that makes the
  coach scroll when it can be avoided. Check new screens at laptop and phone
  widths.
